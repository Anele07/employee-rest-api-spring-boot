# Employee REST API

> Building my first production-style REST API with Java Spring Boot — one endpoint, one test, and one bug at a time.

Welcome to my **Employee REST API** project!

This project was built as part of a backend software engineering job simulation where I was tasked with designing and developing a RESTful web service for managing employee records.

Instead of simply following instructions and copying code, I used this project as an opportunity to learn the fundamentals behind:

- Java
- Spring Boot
- REST APIs
- JSON
- HTTP methods
- JUnit
- Mockito
- Layered application architecture
- Maven
- Unit testing
- Debugging

The goal wasn't just to make the API work.

The goal was to understand **why it works.**
